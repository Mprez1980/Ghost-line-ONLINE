# Ghost Line Online 👻

Welcome to the Ghost Line Online website repository!

## Description

This is the source code for a website dedicated to exploring the ghosting universe. Here you can buy products and learn about paranormal phenomena.

## Features

- **Home Page**: Engaging hero section with call-to-action
- **Shop**: Browse and add featured paranormal products to cart
- **Learn**: Educational content about the ghosting universe
- **About**: Information about Ghost Line Online
- **Contact**: Get in touch with us
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Smooth Navigation**: Smooth scrolling and interactive elements

## File Structure

```
Ghost-line-Online/
├── index.html      # Main HTML file
├── styles.css      # Styling and responsive design
├── script.js       # JavaScript for interactivity
└── README.md       # This file
```

## Getting Started

1. Clone this repository
2. Open `index.html` in your web browser
3. Explore the website!
